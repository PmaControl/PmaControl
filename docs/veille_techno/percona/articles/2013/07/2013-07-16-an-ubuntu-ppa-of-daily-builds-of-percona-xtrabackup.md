## Extrait public

Run Ubuntu and want to try new features of Percona XtraBackup? Well, now you can. We have a Personal Package Archive (PPA) percona-daily/percona-xtrabackup. Every time code is pushed to our main source code repository, the PPA is updated. We are currently building for Ubuntu lucid (10.04LTS), Precise (12.04), Quantal (12.10) and Raring (13.04).
