## Structure detectee

- H3: Official support for MySQL 5.6 and Percona XtraDB Cluster
- H3: pt-online-schema-change (pt-osc) is much more resilient
- H3: pt-upgrade is brand-new
- H3: pt-query-digest is simpler
- H3: Version check is on by default
- H3: pt-stalk and pt-mysql-summary have built-in MySQL options
- H3: pt-stalk –no-stalk is no longer magical
- H3: pt-fk-error-logger and pt-deadlock-logger are standardized
