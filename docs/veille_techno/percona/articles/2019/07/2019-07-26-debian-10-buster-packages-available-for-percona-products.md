## Extrait public

Debian 10 “Buster” packages have been released into the Percona packaging repositories. Recent versions of Percona Server for MySQL, Percona XtraDB Cluster, Percona XtraBackup, Percona Server for MongoDB, Percona Toolkit, and the PMM Client can now be automatically installed via the Debian 10 apt command.
